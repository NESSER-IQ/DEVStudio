# Ocean Theme Extension

A beautiful ocean-inspired dark color theme for HarmonyOS Code Editor.

## Preview

The Ocean theme features:
- Deep blue background colors (#001f3f)
- Bright cyan text (#7fdbff)
- Vibrant accent colors inspired by the ocean
- Excellent contrast for long coding sessions
- Carefully selected colors for syntax highlighting

## Installation

1. Open Extensions view (Ctrl+Shift+X)
2. Search for "Ocean Theme"
3. Click Install
4. Click on the theme in the status bar and select "Ocean"

## Color Palette

- **Background**: Deep Ocean Blue (#001f3f)
- **Foreground**: Bright Cyan (#7fdbff)
- **Selection**: Ocean Blue (#0074d9)
- **Keywords**: Purple (#b10dc9)
- **Strings**: Green (#2ecc40)
- **Numbers**: Orange (#ff851b)
- **Comments**: Light Gray (#aaaaaa)
- **Functions**: Yellow (#ffdc00)

## Customization

You can customize the theme by modifying the `themes/ocean-theme.json` file. See the [Theme Development Guide](../../../docs/THEME_DEVELOPMENT.md) for more information.
